# 栗小铺数据库

完整结构位于 [`shop-common/src/main/resources/db/01-full-schema.sql`](../shop-common/src/main/resources/db/01-full-schema.sql)，按参考商城的实体和 Mapper 组织，包含 31 张业务表。角色种子数据位于同目录 `02-roles.sql`。MySQL 版本要求 8.0.16+，字符集 utf8mb4。

主要模块：`sys_user`、`sys_role`、`sys_permission` 及用户角色/角色权限关联；分类、商品、商品图册、规格；地址、购物车、订单、订单明细与物流；优惠券及使用关系；评价、收藏、轮播图、公告、工厂介绍、反馈、客服消息和消息消费失败记录。表名、主要字段与参考项目的实体和 Mapper SQL 对齐；本项目尚未逐一实现所有业务接口。

## 新建数据库

在 IDEA 的 Database 工具窗口连接 MySQL，然后依次运行：

1. `shop-common/src/main/resources/db/01-full-schema.sql`
2. `shop-common/src/main/resources/db/02-roles.sql`

MySQL 命令行也可执行：

```sql
SOURCE D:/github/project1/ChestnutShopWX/lixiaopu/shop-common/src/main/resources/db/01-full-schema.sql;
SOURCE D:/github/project1/ChestnutShopWX/lixiaopu/shop-common/src/main/resources/db/02-roles.sql;
```

本机库已于 2026-09-23 完成升级，无需再次执行这些步骤。执行前已备份到 `lixiaopu/backups/lixiaopu-before-full-schema-20260923.sql`（Git 忽略该目录）。为了保留已有数据，原来的 7 张表被改名为 `*_study`；创建完整结构后，示例分类和商品迁入正式表。使用其他尚未升级的本地库时，顺序为：

## 登录数据

密码账号在 `sys_user.password` 保存 BCrypt 散列。买家可调用 `POST /api/auth/register` 创建，不预置账号。角色初始化脚本建立 `SYS_ADMIN`、`ADMIN`、`BUYER` 及其权限，不创建管理员账号。

首次系统管理员通过管理端启动时的 `LXP_BOOTSTRAP_USERNAME`、`LXP_BOOTSTRAP_PASSWORD`、`LXP_BOOTSTRAP_PHONE` 一次性初始化。先运行角色脚本，启动成功后移除这三个环境变量。已存在系统管理员时不会再创建。普通管理员由系统管理员调用受保护接口创建。`user_type` 和 `sys_user_role` 必须一致；仅设置其中一个不会获得权限。

Redis 不存数据库密码或微信 session_key。登录会话以用户 ID 和随机会话 ID 定位，保存刷新令牌摘要；访问令牌为短期 JWT。当前 Redis 会话有效期 7 天、访问令牌 15 分钟。两端共用同一 Redis 和 JWT 密钥。配置和接口详见 [认证与权限](认证与权限.md)。
